# Simonetti Home Assistant Add-on Repository

Home Assistant add-on repository by [jsimonetti](https://github.com/jsimonetti).

## Add-ons

| Add-on | Description |
|--------|-------------|
| [Mimirheim](mimirheim/) | MILP energy optimiser for home battery, PV, and EV scheduling against dynamic electricity prices — stable channel |
| [Mimirheim (Edge)](mimirheim-edge/) | Mimirheim edge channel — rebuilt on every commit to `main` |

## Installation

1. In Home Assistant, go to **Settings → Add-ons → Add-on store**.
2. Click the menu (⋮) in the top right and choose **Repositories**.
3. Add the URL:
   ```
   https://github.com/jsimonetti/hassio-apps
   ```
4. The add-ons from this repository will appear in the store.
